# Лабораторная работа №2. Вариант №574821

Доработать приложение из лабораторной работы №1. Существующие CRUD API и key-value-хранилище должны продолжать работать. Добавить CouchDB для постоянного хранения основных объектов.

Дополнительные параметры:
- вложенные данные: история изменения состояния;
- связанная коллекция: связанные объекты;
- индексируемый запрос: поиск по типу и дате изменения;
- аналитический запрос: статистика действий пользователей;
- изменение структуры: добавление schemaVersion и сведений о последнем изменении.

Требования:
1. Перенести основные объекты в CouchDB, сохранив CRUD API первой лабораторной.
2. Реализовать назначенные вложенные данные и связанную коллекцию.
3. Добавить фильтрацию, сортировку, пагинацию и поиск по вложенным полям.
4. Использовать _rev, обработать конфликт изменений и настроить репликацию между двумя узлами.
5. Реализовать аналитический запрос с помощью MapReduce view.
6. Создать Mango-индекс и исследовать индексируемый запрос через _explain.
7. Настроить validate_doc_update и выполнить повторяемую миграцию.
8. Сохранить key-value-хранилище первой лабораторной и использовать его для кэширования запроса к CouchDB с TTL и инвалидацией.
